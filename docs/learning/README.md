## 👋 Welcome!

Hey there! Welcome to the LibreChat Learning Path. If you're a React developer who's comfortable with hooks, components, and state management but haven't ventured into backend territory yet, **you're in exactly the right place**.

This guide will help you understand:
- ✅ **The full stack** - from React button clicks to database storage
- ✅ **Backend fundamentals** - Node.js, Express, REST APIs
- ✅ **Databases** - MongoDB, schemas, queries, relationships
- ✅ **Real-world patterns** - authentication, caching, file uploads
- ✅ **Best practices** - as of November 2025

**The best part?** You already know JavaScript! Backend development is just JavaScript in a different environment. No new language to learn.

---

## 🎯 What You'll Learn

### Frontend Skills (Building on What You Know)
- Advanced React patterns (you know some, we'll show you more)
- TanStack Query (React Query) - game-changer for data fetching
- TypeScript in a production codebase
- Atomic state management (Jotai/Recoil)
- Accessibility with Radix UI
- Tailwind CSS component patterns

### Backend Skills (All New Territory)
- **Node.js & Express** - JavaScript on the server
- **REST API design** - routes, controllers, middleware
- **MongoDB & Mongoose** - NoSQL database & ODM
- **Authentication** - sessions, JWT, OAuth
- **Security** - validation, sanitization, rate limiting
- **Caching** - Redis for performance
- **File handling** - uploads, processing, storage

### Full-Stack Integration
- How frontend and backend communicate
- API design and consumption
- Error handling across the stack
- Real-time updates (Server-Sent Events)
- Performance optimization (caching, queries)
- Testing strategies (Jest, Playwright)

## 🧠 Learning Principles

This guide follows these principles to help you learn effectively:

### 1. 🌉 Bridge from Familiar to New
Every backend concept is explained by connecting it to something you already know in React:

- **Middleware** is like React Context or HOCs
- **Controllers** are like event handlers
- **Services** are like custom hooks
- **Mongoose schemas** are like TypeScript interfaces
- **MongoDB queries** are like filtering arrays
- **Population** is like SQL joins (or looking up refs)

### 2. 🎯 Hands-On, Always
- Every concept has a code example from LibreChat
- Links to actual files with line numbers
- "Try it yourself" exercises
- "Pause and experiment" prompts

### 3. 📊 Visual Learning
- Mermaid diagrams for architecture and data flow
- Sequence diagrams for request/response
- Component trees for React structure
- Database ERDs for relationships

### 4. ⚠️ Intellectual Honesty
- Unclear areas marked clearly (⚠️ UNCLEAR)
- No fabricated explanations
- Investigation paths provided
- Links to official docs (current as of Nov 2025)

### 5. 🎓 Progressive Difficulty
- Start simple, add complexity gradually
- "Beginner" → "Intermediate" → "Advanced" clearly marked
- Can skip ahead if confident

## 🎯 What is LibreChat?

Before diving in, here's what you'll be learning with:

**LibreChat** is an **AI chat aggregator** - it provides a single interface for multiple AI providers:
- OpenAI (ChatGPT, GPT-4)
- Anthropic (Claude)
- Google (Gemini)
- And many more!

Think of it as:
- **Like Spotify** is to music streaming services
- **Like Trello** is to project management
- **LibreChat is to AI chatbots**

### Key Features You'll Explore:
- 🤖 **Multi-provider chat** - switch between AI services seamlessly
- 🔐 **Authentication** - user accounts, login, sessions
- 💬 **Conversation management** - save, search, organize chats
- 🎨 **Agents** - custom AI assistants with tools
- 📎 **File uploads** - images, documents
- 🔍 **Web search** - enhance AI responses with internet data
- 🎨 **Code artifacts** - generate React components in chat
- 🖼️ **Image generation** - DALL-E, Stable Diffusion integration

### Tech Stack (Quick Glance):
**Frontend:** React + TypeScript + Vite + TanStack Query + Tailwind
**Backend:** Node.js + Express + MongoDB + Redis + Passport
**Testing:** Jest + Playwright
**AI:** OpenAI SDK, Anthropic SDK, Google Generative AI, LangChain

**Full details:** [TECH_STACK_RESEARCH.md](./TECH_STACK_RESEARCH.md)
