# Roadmap – Zen Studio Command Centre

> This roadmap is intentionally lightweight and meant to guide your solo-dev work. Dates are approximate and flexible.

## MVP (v1) – Studio Core

**Goal:** A usable internal tool you can adopt for real projects.

- [ ] Project model & project dashboard
- [ ] Attach conversations and artifacts to projects
- [ ] Four built-in specialist agents
- [ ] Project-scoped knowledge base
- [ ] Project export (JSON + Markdown)
- [ ] Initial “Zen” theming and simplified navigation

## v1.1 – UX Improvements

**Goal:** Reduce friction and polish daily use.

- [ ] Better empty states and onboarding for new projects
- [ ] Inline “quick actions” (Run research, Draft PRD, etc.)
- [ ] Improved artifact viewing and navigation
- [ ] Simple search across projects and artifacts

## v2 – Automation & Integrations

**Goal:** Turn the command centre into a more autonomous studio assistant.

- [ ] Scheduled tasks (e.g. weekly project status summaries)
- [ ] Integration with issue trackers (Linear/Jira) for task export
- [ ] Integration with documentation systems (Notion/Confluence)
- [ ] Client-friendly read-only sharing views
